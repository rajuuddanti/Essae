# Reports UI

Reports are intended to be available in the Android app and exportable to Excel/CSV.

Primary reporting areas:
- Admin price updates
- Admin push history
- Store price changes
- Current store prices
- Scale upload sessions
- Scale upload success/failure
- Store/IP mapping

Reports should be readable without requiring technical interpretation. Store name should be resolved from the authoritative stores table and IP/device information should remain available for audit.

Admin sees the Reports area; normal store users do not.
